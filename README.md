## 🚀 How to Host on GitHub Pages (Takes 60 Seconds)

```bash
cd /Users/prasoonparihar/.gemini/antigravity/scratch/prasoon-bachelor-trip

# 1. Commit changes
git add .
git commit -m "🚀 Complete Thailand Bachelor Website with Photos, Map & Playlist"

# 2. Add your GitHub remote and push (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/prasoon-bachelor-trip.git
git branch -M main
git push -u origin main
```

1. Open your repository on GitHub.
2. Go to **Settings** ➔ **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your website will be live at:
   `https://YOUR_USERNAME.github.io/prasoon-bachelor-trip/`
5. Send the link to the boys on WhatsApp! 🍻
