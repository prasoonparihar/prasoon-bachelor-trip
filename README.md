# 🎉 Prasoon's Epic Bachelor Bash — Thailand 2027

> **One last ride before the ring. Thailand, let's gooo!** 🤙

A shareable, funky, animated single-page travel website for Prasoon's bachelor trip to Thailand (Jan 13–19, 2027).

## ✈️ The Journey

| Leg | Flight | Departure | Arrival |
|-----|--------|-----------|---------|
| 🔵 BLR → BKK | IndiGo 6E-1213 | 02:00 IST · Wed 13 Jan | 07:20 ICT · Wed 13 Jan |
| 🟠 BKK → HKT | Thai AirAsia FD3017 | 15:15 ICT · Fri 16 Jan | 16:50 ICT · Fri 16 Jan |
| 🟡 HKT → BLR | Akasa Air QP-624 | 17:00 ICT · Tue 19 Jan | 19:10 IST · Tue 19 Jan |
| 🚗 BKK → Pattaya | Road Trip | Thu 14 Jan morning | ~2 hours |

## 🏙️ Itinerary

- **Jan 13–14**: Bangkok (1 night) · Grand Palace, Khao San Road, Levels/Onyx Club
- **Jan 14–16**: Pattaya (3 nights) · Coral Island, Sanctuary of Truth, Walking Street
- **Jan 16–19**: Phuket (2 nights) · Phi Phi Islands, Bangla Road, Illuzion Club
- **Jan 19**: Return flight HKT → BLR

## 🌟 Features

- 🗺️ **Interactive Map** — Animated plane flying the full route with Leaflet.js
- ✈️ **Boarding Pass Cards** — Real flight data styled as gorgeous boarding passes
- 📅 **Day-by-Day Timeline** — Expandable accordion with all activities
- 🏙️ **City Explorer** — Bangkok, Pattaya & Phuket with tourist spots, coffee shops & nightlife
- 🎰 **Bachelor Dare Wheel** — Canvas spin wheel with 12 epic bachelor dares
- 🎱 **Bachelor Bingo** — 5×5 bingo card with trip challenges (first to Bingo buys a round!)
- 🌟 **Particle Hero** — Animated constellation particle background
- 🎊 **Confetti** — Because of course

## 🚀 Deploy to GitHub Pages

```bash
# 1. Create a new repo on GitHub
git init
git add .
git commit -m "🎉 Prasoon's Bachelor Bash"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/prasoon-bachelor-bash.git
git push -u origin main

# 2. Go to repo Settings → Pages → Source: main branch / root
# 3. Share the URL: https://YOUR_USERNAME.github.io/prasoon-bachelor-bash
```

## 💻 Local Preview

Just open `index.html` in any browser — no build step needed!
